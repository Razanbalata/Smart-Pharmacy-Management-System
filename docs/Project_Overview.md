# PharmaSmart

## Project Description

PharmaSmart is an AI-powered pharmacy inventory and sales management system built with Laravel.

The system helps pharmacies manage:

- Products
- Categories
- Suppliers
- Purchases
- Sales
- Inventory
- Reports
- AI Insights

---

## Project Goals

- Improve inventory management
- Prevent stock shortages
- Reduce expired products
- Track purchases and sales
- Generate business reports
- Provide AI recommendations

---

## Users

- Admin
- Pharmacist
- Cashier

---

## Technologies

- Laravel
- MySQL
- Blade
- Laravel Breeze
- Laravel AI
- Tailwind CSS
